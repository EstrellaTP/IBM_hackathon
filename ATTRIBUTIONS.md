# Attributions

Every open-source library, dataset and external resource used in this project. Add an entry whenever you add a dependency.

## Datasets
- **NHANES 2011–2012 and 2013–2014** (CDC). Physical Activity Monitor minute data (PAXMIN_G, PAXMIN_H), PHQ-9 (DPQ_G, DPQ_H), demographics (DEMO_G, DEMO_H). https://wwwn.cdc.gov/nchs/nhanes/
- **DEPRESJON**. Garcia-Ceja, E., Riegler, M., Jakobsen, P., Tørresen, J., Nordgreen, T., Oedegaard, K. J. and Fasmer, O. B. (2018). *Depresjon: A Motor Activity Database of Depression Episodes in Unipolar and Bipolar Patients*. MMSys'18. https://datasets.simula.no/depresjon/
- **Nurse stress dataset**. *A multimodal sensor dataset for continuous stress detection of nurses in a hospital*. Scientific Data (2022). https://pmc.ncbi.nlm.nih.gov/articles/PMC9159985 · Data: https://datadryad.org/dataset/doi:10.5061/dryad.5hqbzkh6f
- **WESAD**. Schmidt, P., Reiss, A., Duerichen, R., Marberger, C. and Van Laerhoven, K. (2018). *Introducing WESAD, a multimodal dataset for Wearable Stress and Affect Detection*. ICMI 2018. https://ubi29.informatik.uni-siegen.de/usi/data_wesad.html
